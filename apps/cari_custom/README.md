# cari_custom — Cari Terminali Özel Geliştirmeleri

ERPNext üzerine eklenen, kapsam dokümanındaki eksik parçalar:

- **Stock Assignment** (Personel Stok Zimmeti): personele zimmetlenen stok takibi (kapsam modülü 4)
- **Daily Assignment** (Günlük Görevlendirme): personel-araç-bölge bazlı günlük saha görev planı (kapsam modülü 10 — ERPNext `Delivery Trip` temelinin üstüne)
- **Custom Field (fixture)**: Delivery Note üzerine kargo firması + takip no (kapsam modülü 11)

Kurulum: `bench --site <site> install-app cari_custom`
